# Heroku Modules

Модули для юзерботов [Heroku](https://github.com/Heroku-userbot/Heroku), [Ataraxia](https://git.break.wtf/xenside/ataraxia) и [Hotaru](https://github.com/HotaruProject/Hotaru).

## Установка

| Юзербот | Файл модуля | По ссылке | Из файла |
|---|---|---|---|
| Heroku | `<Модуль>.py` | `.dlm <ссылка на файл модуля>` | ответьте на файл командой `.lm` |
| Ataraxia | `<Модуль>_ataraxia.py` | `.dlm <ссылка на файл модуля>` | ответьте на файл командой `.lm` |
| Hotaru | `<Модуль>_hotaru.hmod` | `.ld <ссылка на файл модуля>` | ответьте на файл `.hmod` командой `.ld` |

Все версии модуля лежат в его папке в `Heroku/Modules`. Берите файл для своего юзербота: модуль от одного юзербота на другом не запустится.

# Heroku Modules

Modules for the [Heroku](https://github.com/Heroku-userbot/Heroku), [Ataraxia](https://git.break.wtf/xenside/ataraxia) and [Hotaru](https://github.com/HotaruProject/Hotaru) userbots.

## Installation

| Userbot | Module file | From a link | From a file |
|---|---|---|---|
| Heroku | `<Module>.py` | `.dlm <link to the module file>` | reply to the file with `.lm` |
| Ataraxia | `<Module>_ataraxia.py` | `.dlm <link to the module file>` | reply to the file with `.lm` |
| Hotaru | `<Module>_hotaru.hmod` | `.ld <link to the module file>` | reply to the `.hmod` file with `.ld` |

Every version of a module is in its folder in `Heroku/Modules`. Take the file for your userbot: a module made for one userbot will not run on another.
